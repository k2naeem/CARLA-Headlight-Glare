# media/

Images and the comparison loop shown in the top-level README, taken from a CARLA
run. `exports/` is gitignored, so files must be copied here to be published.

| File | Source |
|---|---|
| `compare_loop.gif` | loop cut from `exports/ego_first_person_compare.mp4` |
| `occlusion_no_glare.png` | crop of the no-glare panel at the occlusion moment |
| `occlusion_with_glare.png` | crop of the with-glare panel at the same moment |
| `lidar_bev.png` | frame from `exports/lidar_bev.mp4` at the same moment |

The pipeline and detection-gate illustrations in the README come from
`slide_figures/`, generated by `make_slide_figures.py`.

Do not prefix filenames with `_` - the root `.gitignore` ignores `_*.png`.
